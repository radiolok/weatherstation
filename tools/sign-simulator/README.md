# Симулятор табло

Страница в браузере, которая рисует экраны табло 102×11 точек теми же шрифтами и иконками, что будут в прошивке. Ползунками задаются температура, осадки, ветер, CO2 и давление. Под каждым экраном показан готовый кадр Mobitec в hex.

Открыть: `index.html` в браузере, сервер не нужен.

- **Режим слотов.** Центр постоянный, левая и правая зоны по 30 столбцов сменяются по очереди. Перевернувшиеся точки подсвечиваются, рядом счётчик точек и столбцов.
- **Полноэкранные варианты** A–E — ранние наброски экранов.

`core.js` — шрифты (цифры 6×11, мелкий 3×5), иконки 11×11, виджеты и кодер кадра. Он же будет источником для генератора C-заголовков прошивки, поэтому файл работает и в браузере, и в Node:

```sh
node -e "const c=require('./core.js'); console.log(c.W, c.H)"
```
