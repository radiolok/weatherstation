# Ключи подписи образов

`dev-ecdsa-p256-TEST-ONLY.pem` — **тестовый** ключ ECDSA P-256 для разработки и CI. Он сгенерирован автоматически, лежит в открытом репозитории и не защищает ничего: образ, подписанный им, загрузчик с этим же ключом примет от кого угодно.

Для устройства, которое висит в доме, нужен свой ключ, которого нет в репозитории:

```sh
imgtool keygen -k ~/secure/ws-release.pem -t ecdsa-p256
west build -b esp32s3_devkitc/esp32s3/procpu --sysbuild fw -- \
  -DSB_CONFIG_BOOT_SIGNATURE_KEY_FILE=\"$HOME/secure/ws-release.pem\"
```

Загрузчик и приложение собираются с одним ключом. Устройство с загрузчиком на тестовом ключе можно перевести на боевой только перепрошивкой MCUboot по USB.
